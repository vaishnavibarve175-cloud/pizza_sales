# Pizza Sales End-to-End Analytics Project

**Tools:** SQL, Python/Pandas, Excel, Power BI

## Project Overview
Analyzed pizza sales data to understand revenue, orders, product performance, and demand patterns.

## Key Work
- Cleaned and validated sales data using Python/Pandas.
- Used SQL to analyze revenue, orders, quantity sold, and product performance.
- Created Excel Pivot Tables and KPIs for sales analysis.
- Built Power BI dashboards to identify sales trends and top-selling products.
- Generated business insights from sales and demand patterns.
